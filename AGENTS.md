# Agents

## General Instructions
1. This is a **SolidStart / SolidJS** project. Do not use React or React-specific patterns.
2. All development, documentation, and AI prompting must be in **English**.
3. Developers must have a **very good understanding of guitar theory and mechanics** (chords, scales, fretboard logic, rhythms, BPM) before making any changes to the codebase, especially within the [src/components/Guitar/](src/components/Guitar/) and [src/utils/guitar.ts](src/utils/guitar.ts) files.
4. Components must be built using DaisyUI and tailwind using custom `.module.scss` only when out of options.

## Project Stack
- **Framework**: SolidStart
- **Library**: SolidJS
- **Styling**: SCSS Modules
- **Language**: TypeScript
- **Dependency Management**: bun

## Guidelines for Guitar Components
- Ensure chord representations are accurate according to standard music notation.
- Maintain consistent timing and rhythm logic for sequences.
- Validate any algorithmic changes to guitar logic against real-world musical theory.
